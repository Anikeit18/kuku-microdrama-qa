# Microdrama pre-promo QA (live demo)

Upload an AI-generated episode (plus its timestamped screenplay) or pick a sample, and get a pass / review / fail
verdict with timestamped flags: black frames, frozen picture, silence, distorted audio, outfit/background changes
inside a scene, and lip sync. Code and evaluation: see the GitHub repo linked from the presentation site.
